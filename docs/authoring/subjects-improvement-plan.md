# 学科体系扩写目录与内容编排

## 1. 改进目标与范围

本方案针对现有“学科体系”文章数量少、先修概念跳跃、正文偏结论式速查、缺少图解和算例的问题，给出后续写作与导航改造清单。本次交付是**目录、逐篇编排和写作验收标准**，不是 22 篇正文；只有标记“现有·扩写”的文章已经存在，其余均为待建页面，不能在导航或正文中提前链接成已发布文章。

目标不是把教材压缩搬到网站，而是建立一条适合初学者的路径：

> 看见现象 → 建立物理图像 → 认识符号和单位 → 读图与计算 → 了解适用边界 → 进入 FAE 验证。

计划将现有 7 篇扩为 **22 篇学习文章，外加学习路径和术语符号表**。其中 6 篇沿用现有正文 URL 扩写；原“磁化与损耗”拆成静态磁化、动态损耗两篇，旧 URL 保留为分流入口；其余主题使用新页面，避免为了改文件名破坏已有链接。

### 1.1 已确认的缺口

- 现有文章直接进入结论和公式，缺少“从现象到概念”的引入。
- 7 篇正文没有各自的教学示意图，公式也普遍没有完整数值算例。
- 磁性分类、磁畴、磁通与磁路、工作点、磁电阻机理等先修内容缺位。
- 软磁、永磁、角度传感分别把多个层次压在一篇中，单篇信息密度过高。
- 学科文章中的选型、验收和排障清单与 FAE 栏目重复，需要明确归属。
- `motor-angle.md` 中本文把 $N_p$ 定义为磁极数，但引用 MOTOR-01 时又写成 $\theta_e=N_p\theta_m$，存在记号冲突；后续正文修订应明确原厂资料中的 $N_p$ 是极对数，本文统一用 $p$ 表示极对数。

### 1.2 内容边界

| 内容 | 学科体系负责 | FAE / 案例库负责 |
| --- | --- | --- |
| 定义、物理图像、经典模型 | 用原创图、通俗类比、公式和算例解释 | 必要时回链，不重复写教科书 |
| 材料与器件的失效机理 | 解释为什么发生、受哪些条件影响 | 转成具体项目的验证项目 |
| 型号和材料牌号 | 只作带型号、版本、条件的示例 | 选型比较、推荐边界、验收判据 |
| 结构与误差 | 解释误差如何进入角度 | 误差预算、校准、仿真、排障和实测 |
| 客户资料 | 只保留可公开、可泛化的机理 | 脱敏且批准后进入案例库 |

每篇学科文章末尾保留最多 3 条“工程出口”，链接到对应 FAE 页面；不复制完整的选型、验收或排障步骤。

## 3. 逐篇内容编排

以下每篇均按统一教学节奏编排：“生活或实验现象 → 标注图 → 概念与公式 → 数值或读图例 → 常见误区 → 工程出口”。表中列出本篇特有的重点；通用要求见第 5 节。教材页码是写作定位锚点，不代表已经逐页核验整章或支持所有后续工程结论。

### A. 磁学语言与物理图像

#### A01 · 从磁场到材料响应：B、H、M、J 与磁通

- **处置与位置：** 扩写 `field-and-measurement.md`；仪器与测量几何移至 B02，只保留单位、基本关系和“局部场不是材料参数”的预警。
- **开头情境：** 同一只线圈，放入铁芯前后为什么空间磁场不同？为什么磁体表面读数和芯片处读数不一样？
- **核心编排：** ① 磁体—气隙—传感器场景图标出各量；② 用“外加激励、材料响应、合成效果”区分 H、M/J、B，但避免把该类比写成严格因果定律；③ $B=\mu_0(H+M)=\mu_0H+J$ 及真空/线性材料近似边界；④ T、mT、G 与 A/m、Oe 换算；⑤ $\Phi=\int\mathbf B\cdot d\mathbf A$ 和均匀场简化；⑥ B/H/M/J、Br/HcB/HcJ 易混词卡。
- **必备图示/算例：** “磁体内部—气隙—芯片”三区域标注图；单位换算阶梯图；一个同时完成 G↔mT、Oe↔A/m 和均匀场磁通估算的练习。
- **常见误区：** B 和 H 都笼统叫“磁场强度”；材料内部的 M 被当作可直接用表面高斯计读取；把 Br 当作芯片处磁通密度。
- **来源与边界：** `BOOK-01` 第 1 章书 p.3 起 / PDF p.12 起，§1.4 书 p.22 / PDF p.31；`UNIT-01`。单位制之外的 CGS 公式必须明确约定，不能混算。
- **工程出口：** 链接 B02 和 FAE 选型页中的“磁场条件确认”。

#### A02 · 磁性从哪里来：磁矩、磁性分类与居里温度

- **处置与位置：** 新建 `magnetic-origin-and-classes.md`；原子磁性只讲到支撑分类和温度直觉，复杂量子推导放进阶折叠区。
- **开头情境：** 铜、铝、铁、铁氧体都被放进磁场，响应为什么不同？铁氧体内部磁矩不是全部同向，为什么仍能有净磁性？
- **核心编排：** ① 电子轨道、自旋与原子磁矩的定性图；② 交换作用和磁矩有序的直观解释；③ 抗磁、顺磁、铁磁、反铁磁、亚铁磁五类对比；④ 磁化率正负与量级只作带条件的读图示例；⑤ 居里温度与热扰动；⑥ “居里温度不是最高工作温度”边界。
- **必备图示/算例：** 五类材料的磁矩排列与 M–T 示意图；根据三幅磁矩排列图判断磁性类别的自测。
- **常见误区：** “有磁矩就一定是铁磁体”；“反铁磁和亚铁磁都没有宏观磁性”；把材料分类直接当器件性能排序。
- **来源与边界：** `BOOK-01` 第 2 章书 p.31 起 / PDF p.40 起，§1.3 书 p.15 起 / PDF p.24 起，§2.4 书 p.42 起 / PDF p.51 起。具体材料温度限值必须查牌号资料。
- **工程出口：** 链接 C03、C05 和 D01。

#### A03 · 磁畴与畴壁：磁体内部为什么分区

- **处置与位置：** 新建 `magnetic-domains.md`，承接现有磁化文章中的磁畴段落并扩展。
- **开头情境：** 一块没有表现出强磁性的铁，内部真的一点磁性都没有吗？
- **核心编排：** ① 单畴与多畴状态对比；② 交换能、各向异性能、退磁能、弹性能和外场能的“能量收支”定性图；③ 180°/90° 畴壁与闭合畴；④ 畴壁不是固定实体边界，而是磁矩方向过渡区域；⑤ 畴壁位移与磁矩转动的预告；⑥ 粉纹法、克尔法等观测方法做选读框。
- **必备图示/算例：** “外加场增大”三格磁畴演变图；闭合畴与开放畴对比；让学生按能量变化解释为何分畴的定性练习。
- **常见误区：** 磁畴等于晶粒；一个磁畴只能有一种晶粒；磁畴图能直接给出芯片处磁场数值。
- **来源与边界：** `BOOK-01` 第 4 章书 p.94 起 / PDF p.103 起，§4.2 书 p.95 起 / PDF p.104 起，§4.3 书 p.100 起 / PDF p.109 起；观测选读 §4.4 书 p.109 起 / PDF p.118 起。示意图不冒充具体样品的显微图。
- **工程出口：** 链接 B01、B03。

#### A04 · 磁各向异性与磁致伸缩

- **处置与位置：** 扩写 `anisotropy.md`；充磁图形和装配检查移至 D03，退磁场定量内容移至 A06。
- **开头情境：** 为什么同一材料沿不同方向磁化，曲线和所需外场不同？压装或灌封后性能为什么可能变化？
- **核心编排：** ① 易轴/难轴与能量随角度变化；② 磁晶、形状、应力各向异性三幅并列图；③ 各向异性磁体与各向同性磁体不等于“有/没有磁晶各向异性”；④ 磁致伸缩 $\lambda=\Delta l/l$ 与饱和磁致伸缩；⑤ 应力—磁化耦合的定性解释；⑥ 与电机噪声、封装应力的连接。
- **必备图示/算例：** 易轴/难轴能量谷图；长棒和薄片对照图；正/负磁致伸缩的长度变化示意；给定形变和原长计算 $\lambda$ 的小算例。
- **常见误区：** 晶粒取向、磁体充磁方向和易轴是一回事；磁致伸缩只与声学噪声有关；把应力效应写成所有材料的固定方向。
- **来源与边界：** `BOOK-01` 第 3 章书 p.71 起 / PDF p.80 起，§3.6 书 p.85 起 / PDF p.94 起；`MAG-01`。具体应力、噪声和可靠性需结构与实测支撑。
- **工程出口：** 链接 A06、D03 与 FAE 排障页。

#### A05 · 磁通、磁阻与磁路：从磁体到气隙

- **处置与位置：** 新建 `magnetic-circuits.md`，补全现有文章缺少的工作点前置知识。
- **开头情境：** 同一块磁体接上不同形状的软磁件，芯片处磁场为什么明显改变？
- **核心编排：** ① 磁通、磁通密度与截面积；② 磁动势、磁阻、磁导；③ 磁路与电路类比的成立范围和失效处；④ 串联气隙为何常占总磁阻的重要部分；⑤ 漏磁、边缘效应与饱和；⑥ 从集总磁路过渡到磁场分布和有限元；⑦ 为 C04 的负载线预留符号表。
- **必备图示/算例：** 磁体—软磁—气隙磁路图；磁路与电路类比对照表；简单均匀截面的磁阻估算，再讨论哪些实际结构不能用该简化。
- **常见误区：** 磁通像电流一样被严格约束在磁芯里；高磁导率材料不会饱和；集总磁路能直接给出芯片敏感区域的全部谐波。
- **来源与边界：** `BOOK-01` 第 1、5、10 章用于量和曲线定位；磁路推导与几何简化须标“教学模型/工程推导”，具体结构用 `SIM-01`、`SIM-02` 与实测验证。正式写作时补足所引用小节，不能仅挂整章来源。
- **工程出口：** 链接 C04、D03、FAE 仿真页。

#### A06 · 退磁场与形状效应：为什么尺寸会改变表现

- **处置与位置：** 新建 `demagnetizing-field-and-shape.md`，承接 A04 和 C04 的形状/负载线内容。
- **开头情境：** 同一牌号、同一体积的磁体，做成细长棒和薄片，为什么抗退磁表现不同？
- **核心编排：** ① 开路磁体的自由磁极与内部反向场；② $\mathbf H_d=-N\mathbf M$ 的符号约定；③ 退磁因子依赖几何与磁化方向，不是材料牌号常数；④ 椭球模型的可算性与圆柱/方块近似的局限；⑤ 形状、负载线与工作点关系预告；⑥ 闭路样品与开路成品的测量差别。
- **必备图示/算例：** 长棒、球、薄片三形态退磁场图；同一 M 下不同 N 的定性工作点图；用明确给定的教学 N 值计算 Hd，再列出实际几何需查表/仿真的条件。
- **常见误区：** 细长磁体“Br 更高”；N 可直接用于任意圆柱和任意磁化状态；退磁场等于外部杂散场。
- **来源与边界：** `BOOK-01` §1.1 内退磁场内容（书 p.12 / PDF p.21）、第 3 章书 p.71 起 / PDF p.80 起、第 4 章书 p.94 起 / PDF p.103 起。具体几何退磁因子和工作点不能只靠教学近似。
- **工程出口：** 链接 B02、C04、C06。

### B. 磁化、曲线与动态行为

#### B01 · 技术磁化与磁滞回线

- **处置与位置：** 新建 `magnetization-and-hysteresis.md`，承接 `magnetization-and-loss.md` 的静态磁化内容；原文件在本批迁移后改作兼容入口或按第 7 节处理，不保留两份正文。
- **开头情境：** 外场回到零，材料为什么没有回到原来的状态？
- **核心编排：** ① 初始磁化曲线与磁滞回线的测量路径；② 畴壁可逆/不可逆位移与磁矩转动；③ Bs、Br、Hc、μi、μmax 在图上的定义；④ B–H 与 J–H/M–H 曲线差异；⑤ 软磁窄回线与永磁第二象限关注点；⑥ 回线面积与每周期磁滞能量；⑦ 由曲线进入参数而非死背定义。
- **必备图示/算例：** 带路径箭头的完整回线；Bs/Br/Hc/磁导率标注图；软磁和永磁并列回线；根据给定坐标读 Br/Hc 和比较回线面积的练习。

- **必备图示/算例：** 四种敏感机理/方向小图；从磁体到数字角度的信号链；正余弦与 atan2 逐象限图；用给定 Bx/By 的四个象限样例计算角度；比较 180° 与 360° 输出曲线。
- **常见误区：** atan2 与普通 arctan 等价；磁场幅值越大越好；ADC 位数就是角度精度；某型号 AGC/SFI 特性可泛化到所有芯片。
- **来源与边界：** `ENC-01`–`ENC-05`、`ENC-08`；机理回链 `BOOK-01` §19.2。所有场窗口、周期、INL、AGC 和温度结论必须绑定具体型号及条件。
- **工程出口：** 链接 D03、D04、D06 和 FAE 选型页。

#### D03 · 编码器磁体、充磁图形与安装几何

- **处置与位置：** 新建 `encoder-magnet-and-mounting.md`，整合 A04、C05、D02、D05 中分散的磁体、充磁、端轴/侧轴/离轴和公差内容。
- **开头情境：** 同一芯片、同一材料牌号，只改变充磁方向、气隙或偏心，角度输出为什么可能完全不同？
- **核心编排：** ① 两极圆柱磁体、多极环、轴向/径向/直径方向充磁图示；② 取向方向≠充磁方向≠传感器敏感轴；③ 端轴、侧轴、离轴、空心轴几何；④ 气隙、偏心、倾斜、轴向窜动如何改变敏感体积内场；⑤ 场幅值、正交性、谐波与杂散场；⑥ 磁体图纸字段：几何、牌号、取向、充磁、极数、相位、镀层、公差；⑦ 2D/3D 分析与实测的分工。
- **必备图示/算例：** 四种安装几何的统一坐标图；充磁方向和芯片敏感轴叠加图；给定气隙/偏心变化画“场变化→角度谐波”的定性链，不把示意当实测频谱；图纸标注自检练习。
- **常见误区：** 磁体越厚/越强越好；端轴磁体可直接用于侧轴；几何对中就保证充磁相位正确；2D 轴对称模型能表达倾斜和周向多极。
- **来源与边界：** `ENC-04`、`ENC-05`、`ENC-07`、`SIM-01`、`SIM-02`；材料和各向异性回链 A04、C04–C06。具体推荐区域只适用于对应型号，不得改写成通用设计规则。
- **工程出口：** 链接 FAE 选型、仿真、误差预算和排障页。

#### D04 · 角度误差从哪里来：偏置、幅值、正交与谐波

- **处置与位置：** 新建 `angle-error-mechanisms.md`，承接原角度文章中的谐波展开，重点建立“物理原因—信号畸变—角度频谱”直觉；完整预算仍归 FAE。
- **开头情境：** 为什么磁体偏心常以每转一次的误差出现，而正余弦幅值不等常出现每转两次的成分？
- **核心编排：** ① 理想正余弦与李萨如圆；② 偏置、幅值不等、正交误差分别怎样把圆变成偏移椭圆/旋转椭圆；③ atan2 后误差随角度变化；④ 1×、2×、p× 等谐波只是线索，不是唯一故障指纹；⑤ 噪声、温漂和机械松动不能都靠静态查表消除；⑥ 可校准系统误差与不可简单校准误差的区分。
- **必备图示/算例：** 三组李萨如图与对应角度误差曲线；用小幅值失配教学数据计算 atan2 并画误差；频谱峰到候选原因的“一对多”表；正反转对比的读图练习。
- **常见误区：** 看见 1× 就断定偏心；校准后残差为零代表所有温度/转速都准确；滤波可同时消除噪声且无动态代价。
- **来源与边界：** `ENC-01`、`ENC-05`、`ENC-06`；误差模型标为教学推导，故障归因需项目实测。具体校准收益不得泛化 ENC-06 的个案数值。
- **工程出口：** 链接 FAE 误差预算与排障页。

#### D05 · 极对数、机械角、电角度与编码器读数

- **处置与位置：** 保留 `motor-angle.md`；安装几何移至 D03，动态输出移至 D06，标定与排障操作保留定义并链接 FAE。
- **开头情境：** 轴只转过 30°，为什么控制器里的电角度可能走了 210°？
- **核心编排：** ① 磁极数 $N_p$ 与极对数 $p=N_p/2$ 的符号约定；② $\theta_e=p\theta_m$、取模、转速与电频率；③ 机械角、电气角、编码器原始角、控制用角四层定义；④ d 轴、A 相轴线、编码器零点与方向；⑤ 机械误差乘 p 进入电角度；⑥ 感应电机转差等不适用边界。
- **必备图示/算例：** 一圈内机械角与电角度斜坡/取模图；d 轴—A 相—编码器零点矢量图；7 对极正算、反算和 p 配错的对照例；修正原第 67 行附近的记号冲突，并说明 MOTOR-01 的 $N_p$ 表示极对数。
- **常见误区：** 极数和极对数混用；编码器原始输出天然就是电角度；机械零位对齐等于电气零点完成标定。
- **来源与边界：** `MOTOR-01`，具体芯片输出定义补对应数据手册。首次调试的限流、限速等安全操作应链接经审核的 FAE 指南，不在原理页自行扩成通用操作规程。
- **工程出口：** 链接 D06、FAE 排障页。

#### D06 · 分辨率、采样、带宽与输出定义

- **处置与位置：** 新建 `encoder-output-and-dynamics.md`，承接 D02、D05 的分辨率、带宽、接口和输出角内容。
- **开头情境：** 两个都是“14 bit 编码器”，为什么一个角度抖动明显，另一个高速跟踪却滞后？
- **核心编排：** ① 分辨率、INL、绝对精度、重复性、噪声、迟滞的区别；② $360°/2^N$ 只是量化步进；③ 采样周期、更新率、带宽、群延迟和相位滞后；④ 滤波对噪声和动态跟踪的取舍；⑤ 绝对/增量、单圈/多圈、ABZ/UVW/SPI/PWM 等输出定义按具体器件拆分；⑥ 上电、丢采样、计数回绕和角度回绕等数据解释问题。
- **必备图示/算例：** 静态分辨率与噪声关系图；采样与延迟时间轴；10/12/14/16 bit 步进计算；给定转速和固定延迟估算电角度滞后，必须同时给出 p；角度跨 359.9°→0.1° 的回绕算例。
- **常见误区：** 位数越多系统精度越高；带宽越高延迟必为零；不同接口的“角度值”不读协议就能直接比较。
- **来源与边界：** `ENC-02`–`ENC-04`、`ENC-06`、`MOTOR-01` 及目标芯片资料。教材不能支撑具体接口、时序、诊断和带宽结论。
- **工程出口：** 链接 FAE 选型、误差预算与排障页。

## 5. 初学者文章的统一编排规范

### 5.1 每篇的内容配额

22 篇正文以“讲透一个中心问题”为单位，避免用更多短碎片替代原来过密的总览：

- 核心入门文章建议约 **1,500–3,000 中文字符**；C04、D02、D03 等桥接篇可更长，进阶折叠内容不计入主阅读路径。
- 至少 **1 张真正承担解释任务的标注图**；C04、D02、D03、D04 等需 2–4 张小图，不能用装饰图或未经解释的仿真云图代替。
- 至少 **1 个读图例、数值算例或场景推演**。不要求为了形式硬编公式，但必须有读者可动手的例子。
- 至少 **3 个常见误区**，以及 2–4 道带答案的自测题；答案放在折叠区。
- 开头列出“先修”和“读完能回答的 3 个问题”；结尾给“本篇小结、工程出口、来源与待确认项”。
- 进阶推导放 `<details>` 或独立选读段，主路径不被量子理论、复数磁导率等推导阻断。

### 5.2 单篇推荐模板

```markdown
# 页面标题

> 本篇回答：一个初学者真实会问的问题。
> 先修：Axx / Bxx；预计阅读：xx 分钟。

## 先看一个现象
## 一张图建立直觉
## 概念、符号与单位
## 公式怎样使用（含完整算例）
## 曲线/结构变化时会怎样
## 常见误区与自测
## 工程出口与适用边界
## 来源与待确认项
```

文章现有 front matter 的 `status/reviewed/owner/tags/sources` 继续保留。可把“先给结论”移到直观引入之后，而不是删除结论；熟练读者仍能快速获取要点，初学者则先获得理解结论所需的图像。

### 5.3 图、公式和例子的规则

- 图必须带坐标、方向、单位和条件；示意图明确标“示意，非按比例/非实测”。
- 优先原创 SVG；源文件放 `docs/assets/diagrams/src/`，页面引用同名静态 SVG。复杂图拆成多张小图，不制作移动端不可读的大图。
- 不复制教材整页、整节或大段原文；教材图若需借鉴，只重绘概念关系并标来源，具体数值重新核对。
- 公式先写符号、单位和适用条件，再给代入、计算和结果解释；不能只展示定义式。
- 算例优先使用明确的教学假设。真实器件/材料算例必须绑定型号、版本、温度、磁场、波形和测试条件。
- 类比只负责建立直觉，紧跟一句“类比在哪里失效”。例如磁路类似电路，但漏磁和饱和使其不服从简单电路直觉。

一篇文章只有同时满足以下条件，才可从“草稿”改为“已复核（来源级）”：

- [ ] 中心问题单一，先修链接真实存在，目标读者能在开头判断是否要读。
- [ ] 开头有可感知的现象或问题，而非直接堆定义。
- [ ] 主图有标注、单位、方向和适用条件，在手机宽度下可读。
- [ ] 至少一个完整读图例/算例/场景推演，包含输入、步骤和结果解释。
- [ ] 公式中的符号、单位、正负号和近似条件明确。
- [ ] 有常见误区、自测与答案，能检查“是否真懂”而非只检查记忆。
- [ ] 教材引用含章节、书页和 PDF 页；章节起始页写“起”，具体数值和公式已回看扫描页。
- [ ] 器件和牌号结论有现行来源及条件；教材不被用来证明芯片规格或项目精度。
- [ ] 教学示意、工程推导、原厂数据、项目实测在文字上可区分。
- [ ] FAE 出口不超过 3 条，未复制完整选型/排障流程。
- [ ] 无客户敏感信息，无教材整页扫描或大段受版权保护原文。
- [ ] `mkdocs build --strict` 通过，内部链接、图片、公式和来源 ID 可到达。
- [ ] 在约 390 px 宽度下检查表格、公式、图片和折叠答案。
- [ ] 同步更新目录、学习路径、术语表、知识地图和首页文章计数。
