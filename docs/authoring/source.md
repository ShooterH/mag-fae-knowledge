# 来源模板

复制以下内容到 `docs/sources/vendor.md` 或新建来源页，再在正文引用 ID。

```markdown
<a id="XXX-00"></a>
### XXX-00 · 简短题名

- **机构/版本：** 机构，版本/发布日期
- **资料：** [准确标题](https://example.com)
- **访问日期：** YYYY-MM-DD
- **支持：** 这份资料可以直接支持哪些论断。
- **边界：** 只适用于哪些型号、工况或测试条件；不能支持什么。
```

## 登记检查

- [ ] 标题、机构、版本和日期能从原页面确认。
- [ ] URL 可直接访问，不是搜索结果页或转载页。
- [ ] “支持”只写资料中明确表达的内容。
- [ ] “边界”写明型号、温度、磁场、测试夹具等限制。
- [ ] 没有把摘要、二手解读或营销文案当作原始资料。
- [ ] 需要付费或已失效的资料明确标注，不伪造全文引用。
