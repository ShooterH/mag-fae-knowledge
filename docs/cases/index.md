# 案例库

案例库只收录**已脱敏、可追溯、获准公开**的项目记录。首版不编造客户名称、测试数字或“成功案例”。

## 一条合格案例必须包含

- 匿名项目编号与产品大类，不包含客户名、联系人、图纸编号或可反推信息。
- 机械/电气接口、磁体、气隙、温度、转速和测试工装条件。
- 现象、复现步骤、原始测量或日志摘要。
- 根因证据链，以及被排除的假设。
- 对策、验证结果、适用范围和遗留风险。

## 使用模板

从[案例模板](../authoring/case.md)复制一份到本目录，文件名建议使用 `CASE-YYYYMMDD-主题.md`，并在 `cases/.pages` 中决定是否公开导航。

!!! warning "公开前审查"
    客户资料默认不公开。即使去除名称，也要检查图纸局部、独特结构尺寸、批次信息和日志中的路径/序列号是否可识别。未经书面批准，不进入公开仓库。
