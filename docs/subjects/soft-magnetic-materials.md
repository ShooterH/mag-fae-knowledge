# 软磁材料与选型

<div class="kb-status">
<span>状态：已复核（来源级）</span><span>复核：2026-10-25</span><span>教材：第 7、8 章</span>

## 适用范围

本文用于电机定转子、磁屏蔽、极靴、磁通回路和传感磁路中的软磁材料初选，重点解释“低矫顽力、高磁导率、高饱和、低损耗”之间的取舍。

不提供具体牌号的磁化曲线、损耗表或热处理窗口；这些必须向材料供应商索取对应厚度、频率和温度的数据。

## 先给结论

1. **软磁的“软”是磁学意义：容易磁化和退磁，不是机械硬度。**
2. **选型不是找“磁导率最高”的材料，而是同时满足饱和、损耗、频率、厚度、应力、成本和加工。**
3. **饱和磁通密度决定磁路能否做得小；磁导率决定小信号响应；损耗决定高频温升。** 三者经常互相牵制。
4. **叠片、绝缘、切割和压装会改变最终性能。** 材料数据表上的曲线不等于成品磁芯曲线。
5. **磁屏蔽不是简单地加一块高 μ 材料。** 还要看饱和、厚度、层数、开口、接地和外部场方向。

## 主要软磁材料

| 材料 | 相对优势 | 主要限制 | 典型场景 |
| --- | --- | --- | --- |
| 无取向硅钢 | 饱和较高、成本可控、加工成熟 | 高频损耗较大；冲剪应力影响性能 | 电机定转子、低频磁路 |
| 取向硅钢 | 沿轧向磁性能好、损耗低 | 方向性强，垂直方向性能差 | 变压器、特定方向磁路 |
| NiFe 合金 | 高磁导率、低矫顽力 | 饱和与成本随牌号差异大；应力敏感 | 精密磁屏蔽、弱信号磁路 |
| CoFe 合金 | 高饱和磁通密度 | 成本高、加工和脆性限制 | 高功率密度、航空/特殊电机 |
| 非晶合金 | 低损耗、高磁导率、薄带 | 饱和中等、退火和脆性、加工受限 | 高频变压器、电机探索 |
| 纳米晶 | 高磁导率、低损耗 | 饱和中等、成本与热处理 | 高频电感、共模扼流、屏蔽 |
| 软磁铁氧体 | 电阻率高、高频损耗低 | 饱和低、温度依赖明显 | 高频变压器、EMI 滤波 |
| 铁粉芯/软磁复合材料 | 三维磁路、分布式气隙、绝缘性好 | 磁导率较低、模压密度与损耗限制 | 电感、轴向磁通电机、特殊磁路 |

VAC 将 NiFe、CoFe、非晶、纳米晶等作为不同软磁系列，选型维度包括低 $H_c$、高 $\mu$、高 $B_s$ 和电阻率 [SOFT-01](../sources/vendor.md#SOFT-01)。教材第 7、8 章则从性能参数和金属软磁材料展开 [BOOK-01，第 7 章书 p.173 起 / PDF p.182 起，第 8 章书 p.195 起 / PDF p.204 起](../sources/book.md#BOOK-01)。

## 选型的六个维度

### 1. 工作磁通与饱和裕量

先算磁路需要多少磁通，再除以有效截面积得到工作 $B$。高温、瞬态电流和短路工况会使 $B$ 升高；必须留饱和裕量。软磁进入饱和后，磁导率快速下降，磁路等效气隙变大，电流和损耗都会上升。

### 2. 频率与损耗

低频大功率电机常优先硅钢；高频小功率场景可能选铁氧体、纳米晶或粉末材料。损耗要按**实际波形、频率、磁通摆幅、直流偏置和温度**比较，而不是只看材料手册中的一个点。

### 3. 磁导率与信号电平

高 $\mu$ 材料适合弱场，但可能在小信号下就受应力、切割或饱和影响。磁屏蔽、互感器磁芯和传感器聚磁件要区分“初始磁导率”“幅值磁导率”和“有效磁导率”，它们的测试条件不同。

### 4. 厚度与叠压

薄片降低涡流，但增加加工、叠压和填充系数成本。叠片绝缘不良、毛刺短路、焊接连续导电会形成涡流路径，使实际损耗高于材料曲线。

### 5. 机械与热

冲剪、弯曲、压装、过盈配合和灌封都会引入应力；磁致伸缩材料还可能有噪声和尺寸变化。退火可以释放应力，但可能影响尺寸、镀层和装配顺序。

### 6. 成本与供应

CoFe 的高饱和很吸引人，但成本和加工难度高；纳米晶的性能依赖热处理；铁氧体的高频优势可能被低 $B_s$ 抵消。选型要把材料、加工、良率和供应周期一起算。

## 磁屏蔽的特殊性

屏蔽效能不是单一材料参数，而是“源—屏蔽—敏感点”的系统问题：

- 低阻抗、强场源需要先考虑屏蔽层饱和，再考虑 $\mu$；
- 高频场更依赖导电层的涡流屏蔽，低频场更依赖高 $\mu$ 磁通分流；
- 接缝、开口、线缆入口会显著泄漏；
- 多层不同材料可以兼顾低频和高频，但层间绝缘和机械固定要设计；
- 屏蔽件被磁化后可能成为新的偏置源，必要时消磁。

对编码器而言，电机漏磁、绕组端部场和相邻磁体是常见干扰源。先用三维场测量确定干扰方向和频谱，再决定屏蔽形状，比直接贴一块坡莫合金更可靠。

## 软磁件在编码器中的角色

- **磁屏蔽/导磁罩：** 改变外部杂散场路径，同时可能改变传感器处的有效场。
- **极靴/聚磁件：** 把磁体场引导到敏感区，几何比材料牌号更关键。
- **电机转子/定子：** 提供主磁路，饱和与损耗影响转矩和温升。
- **安装支架：** 若使用铁磁螺钉或卡簧，可能形成意外磁路，改变气隙场。

任何新增铁磁件都要在目标结构下复测，不能只按材料“高 μ”推断改善。

## 来料与设计验证

- [ ] 材料牌号、厚度、密度、叠压系数、绝缘涂层和热处理状态是否明确？
- [ ] 是否有目标频率、磁通摆幅和温度下的损耗曲线？
- [ ] 冲剪方向、毛刺、焊接和压装应力是否受控？
- [ ] 成品磁芯的有效磁导率是否实测，而非只引用原材料数据？
- [ ] 磁屏蔽是否在真实源方向和强度下测过屏蔽效能？
- [ ] 是否评估了铁磁支架/螺钉对编码器磁场的影响？

## 常见误区

!!! warning "不要这样选软磁"
    1. 只看 $\mu_i$，忽略饱和和损耗。
    2. 用直流 B–H 曲线预测高频温升。
    3. 认为叠片越薄越好，忽略填充系数和加工成本。
    4. 用一块高 μ 材料包住传感器，却没检查它是否被电机漏磁饱和。
    5. 把材料手册曲线当成成品磁芯曲线，不评估冲剪和压装。
