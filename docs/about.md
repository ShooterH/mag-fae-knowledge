# 关于本库

## 它解决什么问题

这是一套面向**磁编码器 FAE** 的个人工程知识库，服务于三类高频工作：

1. 客户提出转速、精度、安装空间、温度、接口和成本约束时，快速形成选型问题清单与验证计划。
2. 客户结构尚未定型时，判断磁体、气隙、偏心、倾斜和屏蔽中哪些因素值得建模，哪些应先用解析估算或实测筛选。
3. 现场角度跳动、丢步、温漂、接口异常时，按证据链排查，而不是直接归因于“芯片不行”或“磁铁不行”。

## 设计原则

- **任务入口与学科体系并存。** 同一篇内容只维护一份，首页和工作流页面负责指路。
- **来源可追溯。** 重要事实附来源 ID；教材标书页和 PDF 页，外部资料保留版本、URL 和访问日期。
- **区分证据等级。** 标准、原厂资料、教材、工程推导和项目实测不能混为一谈。
- **可增改。** 内容为普通 Markdown，目录和 GitHub Actions 自动生成网站。
- **移动端优先可读。** 导航可折叠、表格可横向滚动、正文控制行宽、搜索在本地完成。

## 明确不做什么

- 不公开分发受版权保护的整本教材或大段扫描页。
- 不保存客户名称、图纸、联系方式、生产参数或未经批准的测试日志。
- 不把某颗芯片的典型精度、气隙或校准结果泛化成行业结论。
- 不虚构仿真云图、实测数据或客户案例。
- 不替代功能安全、安规、EMC、可靠性和量产验证。

## 内容状态

| 状态 | 含义 |
| --- | --- |
| `草稿` | 结构已建立，事实仍可能缺来源或待复核 |
| `已复核` | 已对照当前列出的来源检查；不表示适用于所有型号 |
| `待实测` | 推导或工程建议需要样机数据确认 |
| `已归档` | 保留作历史参考，不应作为当前设计依据 |

首版文章以“已复核”或“待实测”明确标识；若没有真实测试，不会写成已验证。

## 技术栈

- MkDocs Material：静态站点、中文搜索、响应式导航
- Markdown + Git：内容可审查、可回滚、可协作
- GitHub Actions + GitHub Pages：推送 `main` 后自动构建发布
