# 磁编码器误差预算

<div class="kb-status">
<span>状态：已复核（方法级）</span><span>复核：2026-10-25</span><span>适用：系统角度误差分解</span>
</div>

## 适用范围

本文用于把磁编码器系统角度误差拆成可测量的项目，建立预算、设计验证和现场排障的共同语言。

不提供某一结构的保证误差，也不把数据手册的 INL 直接当成系统精度。具体数值必须来自目标型号、磁体、结构和实测。

## 先给结论

1. **先定义参考角与统计口径。** 同一组数据用最大值、RMS 或 ±3σ 表达，结论可能差很多。
2. **系统误差和随机误差要分开。** 偏心、磁化偏差、装配倾斜可通过校准改善；噪声、振动、随机干扰不能靠查表消除。
3. **误差频谱是根因线索。** 1×、2×、极对数相关的高阶项，分别指向不同的机械/磁体机制。
4. **理想均匀旋转场中，幅值变化不一定改变角度；真实场有梯度和谐波，所以气隙仍会产生 INL。**
5. **校准集与验证集必须分开。** 用同一批点拟合又验证，会高估校准效果。
6. **合成误差不能简单相加。** 独立随机项可 RSS，系统偏差按区间/最坏情况处理，相关项要保留相关性。

## 定义清楚再测

至少约定：

- **参考角度：** 高精度编码器、光学基准、工装分度头还是电机电角度？其不确定度是多少？
- **机械行程：** 0–360° 全圈、有限角度还是多圈？
- **方向：** 正转、反转、往返；是否分别统计？
- **温度：** 哪些温度点？稳定时间？热点在哪里？
- **样本：** 多少台、多少磁体批次、多少安装次数？
- **统计：** 最大绝对误差、RMS、±3σ、95% 区间？
- **校准：** 未校准、单温校准、多温校准？校准点数量？

没有这些条件，“精度 ±0.5°”无法比较，也无法验收。

## 误差分类与典型特征

| 误差项 | 典型表现 | 主要机制 | 可否校准 |
| --- | --- | --- | --- |
| 零点偏移 | 全圈近似常数偏差 | 安装零位、磁化相位、算法零点 | 可，若稳定 |
| 1× 正弦 | 每转一次起伏 | 偏心、磁体倾斜、端轴磁化偏移、离轴 | 部分可 |
| 2× 正弦 | 每转两次起伏 | 椭圆度、磁体/结构二重不对称、倾斜组合 | 部分可 |
| 高阶周期 | 每转 $k$ 次或极对数相关 | 多极充磁、磁场谐波、插值 | 部分可，需足够分辨率 |
| 随机噪声 | 角度抖动、重复性差 | 传感器噪声、ADC、EMI、振动 | 不可查表消除 |
| 迟滞 | 正反向同角度读数不同 | 轴承、联轴器、磁体松动、磁滞 | 只能机械/材料改善 |
| 温漂 | 零点/斜率随温度变 | 磁体 Br、芯片偏移/灵敏度、结构膨胀 | 多温校准可改善 |
| 动态滞后 | 随转速/加速度增大 | 滤波、采样、算法延迟 | 可补偿，但需模型 |
| 量化 | 阶梯状输出 | 分辨率限制 | 不可消除，只能提高位数/插值 |

“每转一次”不一定就是偏心，“每转两次”也不一定就是椭圆。**频谱是假设生成器，不是根因证明。** 还要结合气隙、磁体、工装和温度实验。

## 误差合成

若各误差项相互独立且近似随机，可用均方根估算：

$$
e_{\mathrm{rss}}=\sqrt{\sum_i e_i^2}
$$

若要做保守设计，可用绝对值上界：

$$
e_{\mathrm{worst}}=\sum_i |e_i|
$$

但真实系统常有相关性：温度同时改变磁体和芯片；偏心同时改变 1× 与气隙。此时应：

- 把相关项合并成一个“工况相关误差”；
- 用蒙特卡洛/敏感性分析处理公差分布；
- 用实测协方差或 worst-case 包络验证；
- 不用 RSS 把系统性偏差“平均掉”。

## 磁体与机械的贡献

### 气隙

在理想、均匀、纯旋转的横向场中，整体幅值变化只改变 $B_x/B_y$ 的尺度，$\arctan$ 后角度不变。但真实端轴磁体存在边缘漏磁、轴向分量、非正弦空间分布和传感器敏感体积平均，气隙变化会改变波形，产生 INL。

气隙还决定场强是否落在芯片窗口：

- 太大：信噪比下降，外部干扰占比上升；
- 太小：饱和、削顶、装配碰撞风险；
- 公差堆叠：磁体厚度、PCB 厚度、焊膏、壳体、轴承游隙都要算。

### 偏心

磁体轴与传感器中心不重合，或磁体相对旋转轴偏心，会引入低阶角度误差。偏心还改变传感器处的场强和轴向分量。仅靠芯片校准不能消除，因为机械偏心可能随装配、温度和转速变化。

### 倾斜

磁体端面/传感器平面不平行，会让 $B_z$ 分量进入，改变横向场的幅值和相位。倾斜误差可能表现为 1×、2× 或更高阶，取决于几何。对 3D Hall，倾斜有时可通过矢量算法部分补偿；对只测两轴的结构，残余误差更明显。

### 轴跳动与松动

轴向跳动改变气隙，径向跳动改变偏心；磁体与轴相对滑动会产生零点漂移和迟滞。温度循环后胶层蠕变、压装松弛也会引入慢漂移。

## 芯片与算法贡献

- **INL：** 数据手册通常在指定磁场、温度和夹具下测得，不等于客户结构下的误差。
- **噪声：** 与带宽相关；滤波降低噪声但增加延迟。
- **偏置/增益/正交误差：** 可通过椭圆拟合或傅里叶校准改善，但需要覆盖工作温度。
- **量化：** 12 bit 约 0.088°/LSB，16 bit 约 0.0055°/LSB；分辨率不是精度。
- **算法：** $\arctan$ 查表、CORDIC、插值、滤波和角度展开都会引入误差；多圈展开错误会造成跳变。
- **诊断：** 饱和、断线、场强异常若未检测，系统可能输出看似合理的错误角度。

Allegro 的 A1335 应用笔记把 IC 非线性、温漂、噪声与磁场幅值/非线性分开讨论，并给出特定器件、磁体和条件下的线性化改善案例 [ENC-06](../sources/vendor.md#ENC-06)。这类数字不能直接作为其他系统的校准收益。

## 校准：能消除什么，不能消除什么

### 可以改善

- 稳定的零点偏移；
- 幅值不等、正交误差；
- 可重复的低阶谐波；
- 特定温度下的系统性弯曲。

### 不能可靠消除

- 随机噪声和 EMI；
- 机械松动、轴承间隙、联轴器背隙；
- 磁体局部缺陷、裂纹、充磁不均；
- 随时间变化的磨损和胶层蠕变；
- 未覆盖温度/位置的误差。

### 正确做法

1. 用独立参考编码器和精密转台采集全圈数据；
2. 正反向、多温度、多气隙/偏心条件分别采集；
3. 拟合低阶傅里叶系数或分段多项式，保留物理可解释性；
4. 用**独立验证集**评估残差，不用训练集自证；
5. 把校准版本、温度点、工装和有效期写入追溯；
6. 监测校准后残差，异常时触发返工而不是继续补偿。

## 测量与频谱分析

建议采集：

- 参考角、原始 $B_x/B_y/B_z$、芯片角度、温度、气隙/位移；
- 正反转各至少 3 圈，等角度或等时间采样；
- 最大转速、加速度、电机通电状态；
- 不同样本和装配次数。

对角度误差做 FFT，观察 1×、2×、极对数倍频和随机底噪。再把候选机制做受控实验：

| 实验 | 观察 | 可支持的判断 |
| --- | --- | --- |
| 改变气隙 | 幅值、INL、噪声 | 场窗口/波形敏感性 |
| 人为径向偏心 | 1× 幅值 | 偏心贡献 |
| 加垫片倾斜 | 2×/1× 变化 | 倾斜贡献 |
| 旋转磁体 180° | 误差相位/极性变化 | 磁化不对称 |
| 正反向 | 迟滞 | 机械/磁滞 |
| 温度循环 | 零点/斜率/残差 | 温漂与不可逆变化 |
| 电机通电 | 随机/窄带干扰 | 杂散场/EMC |

## 现场沟通话术

- “请先把精度定义成：全温区、全圈、正反向、多少样本下的最大绝对误差，还是 RMS？”
- “这个 1× 误差是装配偏心还是磁体充磁偏差？我们可以做偏心/旋转磁体实验分离。”
- “校准能降低重复性误差，但不能消除随机噪声和松动；先把机械和磁场稳定下来。”
- “数据手册的 INL 是在其测试条件下得到的，我们需要在您的结构和温度下复测。”
