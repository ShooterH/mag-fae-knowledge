# 磁编码器选型工作流

<div class="kb-status">
<span>状态：已复核（方法级）</span><span>复核：2026-10-25</span><span>适用：客户项目早期到样机验证</span>
</div>

## 适用范围

本文给出从客户需求到候选方案、验证计划和量产导入的工作流，适用于磁编码器的技术支持与选型建议。

不直接推荐具体型号。型号选择必须结合本厂产品线、目标芯片现行数据手册、磁体供应和客户结构；任何参数都要回到具体型号和测试条件。

## 先给结论

1. **先定义“角度误差”的统计口径，再谈多少度。** 没有温度、行程、校准方式、样本量和置信区间的精度数字不可验收。
2. **把需求分成“必须满足”和“可权衡”。** 先排除不满足安全、接口、温度和磁场的方案，再做评分。
3. **分辨率、精度、重复性、迟滞、带宽是五个不同指标。** 高 bit 数不能替代系统精度。
4. **磁编码器是“芯片 + 磁体 + 结构 + 算法 + 校准”的系统。** 只选芯片，客户结构仍可能让角度失效。
5. **样机验证必须覆盖最坏工况。** 常温静态测试通过，不代表高低温、最大气隙、最大转速和杂散场下可用。

## 第一步：把一句话需求拆成参数

客户常说“我要一个高精度、便宜的编码器”。需要转成可执行问题：

### 机械与运动

- 机械角范围：单圈 360°、有限角度还是多圈？
- 轴型：实心轴、空心轴、端轴、侧轴？安装空间？
- 转速范围、加速度、换向频率？
- 允许的轴向/径向游隙、跳动、偏心、倾斜？
- 目标寿命、振动、冲击、防护等级？

### 精度与动态

- 精度定义：绝对误差、INL、重复性、迟滞、分辨率还是短期噪声？
- 统计口径：最大误差、RMS、±3σ、样本量？
- 是否允许客户产线校准？校准点数、温度点？
- 带宽、更新率、延迟、抖动要求？
- 正反转是否要求对称？

### 环境

- 工作/存储温度、温变速率、热点位置？
- 湿度、盐雾、油污、粉尘、清洗剂、辐射？
- 电机杂散场、相邻磁体、外部磁铁、电流频率？
- EMC、ESD、功能安全、诊断、冗余要求？

### 电气与接口

- 供电电压、电流、功耗、上电时间？
- 输出：模拟、PWM、SPI、I²C、ABZ、UVW、SSI、BiSS、CAN 等？
- 绝对/增量、单圈/多圈、 cero/零点定义？
- 线束长度、连接器、接地、屏蔽？

### 商业与项目

- 年用量、目标单价、开发周期、量产节点？
- 供应周期、替代料、生命周期？
- 质量体系、PPAP、失效率目标？

## 第二步：建立“必须/权衡”矩阵

| 类别 | 必须满足（Pass/Fail） | 可权衡（Score） |
| --- | --- | --- |
| 安全/法规 | 电压、隔离、功能安全、安规 | 诊断覆盖率 |
| 环境 | 温度、防护、EMC、腐蚀 | 余量、封装尺寸 |
| 机械 | 空间、轴型、公差、寿命 | 重量、安装便利性 |
| 性能 | 最小精度、带宽、接口 | 分辨率、延迟、噪声 |
| 供应 | 生命周期、认证、交期 | 价格、MOQ、替代性 |

先做 Pass/Fail，能避免“价格很低但高温不够”的方案进入评分。评分权重应在看候选之前确定，否则容易事后找理由。

## 第三步：从结构反推磁体与芯片

选型不是先选芯片再找磁体。应同时考虑：

1. **磁体位置：** 端轴、侧轴、多极环、离轴。
2. **磁体材料：** 铁氧体、NdFeB、SmCo；温度、腐蚀、成本。
3. **充磁：** 径向、轴向、多极；极数、相位、极性。
4. **气隙与公差：** 最坏机械堆叠下的最小/最大气隙。
5. **芯片场窗口：** 目标型号在温度、气隙和磁体公差下的场强/方向。
6. **算法：** 是否需要差分、3D、杂散场补偿、片上线性和温度补偿。
7. **校准：** 产线、终端还是不做；校准数据存储和追溯。

例如，AS5600 的 AGC 可以在其规定范围内调整气隙，但推荐磁体尺寸、气隙和偏心条件是型号特定的 [ENC-04](../sources/vendor.md#ENC-04)。Melexis 的端轴磁体选择也明确绑定其 Triaxis/SFI 型号 [ENC-05](../sources/vendor.md#ENC-05)。**不能把一份应用笔记的推荐值直接复制给另一颗芯片。**

## 第四步：建立误差预算

在打样前先做一版预算，把总误差拆成：

- 芯片 INL、噪声、温漂、迟滞；
- 磁体充磁偏差、材料批次、温度系数；
- 气隙、偏心、倾斜、轴跳动；
- 安装应力、胶层、螺钉、磁体松动；
- 校准残差、量化、滤波延迟；
- 外部杂散场和电机电流干扰。

独立随机项可用均方根估算，系统性偏差应按区间叠加或 worst-case 处理。详细方法见[误差预算](error-budget.md)。

## 第五步：候选方案评分

建议使用“门槛 + 加权评分”：

$$
S=\sum_i w_i s_i
$$

其中 $w_i$ 之和为 1，$s_i$ 为归一化得分。对每个候选记录：

| 项目 | 权重 | 候选 A | 候选 B | 证据/假设 |
| --- | --- | --- | --- | --- |
| 精度余量 | 0.25 |  |  | 数据手册 + 预算 |
| 温度 | 0.20 |  |  | 最坏温度曲线 |
| 接口/固件 | 0.15 |  |  | 平台兼容性 |
| 磁体/结构 | 0.15 |  |  | 空间与公差 |
| 供应/成本 | 0.15 |  |  | 报价/交期 |
| 校准/量产 | 0.10 |  |  | 产线能力 |

评分必须附证据。若某格只是“供应商说可以”，标为假设，不应当作已满足。

## 第六步：样机验证计划

最小验证集：

1. **静态全行程：** 多点正反向，测重复性、迟滞、INL。
2. **最坏气隙：** 最小/最大气隙，含偏心/倾斜。
3. **温度：** 最低、常温、最高，至少一个温度循环。
4. **动态：** 最大转速、加速度、换向，测延迟和抖动。
5. **干扰：** 电机通电、相邻磁体、外部磁铁、线束布置。
6. **寿命/振动：** 按项目风险安排。
7. **校准验证：** 校准集与验证集分开，避免自证。

验证报告要记录参考编码器、工装、探头、采样率、滤波、环境温度和样本量。

## 第七步：量产导入

- 来料磁体验收：固定夹具、指定场分量、批次抽样。
- 芯片/模组校准：工位、参考件、校准有效期、数据存储。
- 追溯：磁体批次、芯片批次、校准版本、固件版本。
- 变更管理：磁体供应商、牌号、充磁夹具、芯片 Revision 变更都要重新验证。
- 失效分析：保留原始角度、场强、温度、电源和协议日志。

## 常见选型陷阱

!!! warning "六个高频错误"
    1. 用分辨率代替精度。
    2. 只看常温数据手册，不看客户最坏气隙和温度。
    3. 先定芯片，再让结构迁就磁体。
    4. 把某型号的推荐磁体/气隙当成所有型号通用。
    5. 用软件校准掩盖机械松动、磁体缺陷或噪声。
    6. 没有定义“通过”的统计口径，导致样机阶段争议。
