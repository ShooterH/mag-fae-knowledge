# 磁编码器结构/磁路仿真建议

<div class="kb-status">
<span>状态：已复核（方法级）</span><span>复核：2026-10-25</span><span>适用：静磁/准静态磁路评估</span>
</div>

## 适用范围

本文用于判断客户结构是否需要仿真、选 2D 还是 3D、如何设置材料与边界、怎样判断收敛，以及如何把仿真与实测关联。

不提供某一软件的逐步操作，也不展示虚构的云图或精度结果。软件版本、菜单和求解器能力以官方文档为准。

## 先给结论

1. **先定义要预测的量，再选软件和维度。** “看一下磁场”不是目标；应明确是芯片敏感体积内的 $B_{x,y,z}(\theta)$、幅值、谐波还是角度误差。
2. **2D 只适合平移不变或轴对称问题。** 短磁体端部、径向/多极充磁、偏心、倾斜、离轴传感器通常需要 3D。
3. **求解器报“收敛”不等于模型已验证。** 还要检查网格、边界、材料外推和观测量是否稳定。
4. **材料曲线和充磁方向比“网格细不细”更容易出错。** BH 外推、Br 温度、永磁模型和坐标方向必须可追溯。
5. **仿真的价值在于比较方案和做敏感性，不是替代实测。** 没有实测相关性的模型，不能用来承诺客户精度。

## 第一步：把工程问题写成仿真问题

一个合格的仿真任务应包含：

- **几何：** 磁体、传感器封装/敏感区、气隙、轴、壳体、屏蔽件、螺钉；是否省略、为什么。
- **坐标：** 旋转轴、磁化方向、传感器敏感轴、角度零点。
- **材料：** BH 曲线、Br、$H_{cJ}$、回复磁导、温度、镀层（若影响）。
- **激励：** 永磁体剩磁/磁化分布；是否有电流、外部场。
- **观测量：** 传感器敏感体积平均后的 $B_x/B_y/B_z$、幅值、角度误差、谐波。
- **工况：** 角度扫描、气隙、偏心、倾斜、温度、公差。
- **验收：** 与什么实测比较，允许残差多少。

如果连“传感器敏感区是一个点还是一个体积”都没定义，后面的网格和云图没有可比性。

## 2D、轴对称与 3D 的选择

| 模型 | 适用条件 | 不适用/风险 |
| --- | --- | --- |
| 2D 平面 | 几何、材料、激励沿出平面方向近似不变；端部效应可忽略 | 短磁体、端部漏磁、倾斜、离轴、周向多极 |
| 2D 轴对称 | 几何、材料、磁化、边界都绕同一轴旋转对称 | 径向/直径充磁、多极充磁、偏心、开槽、螺钉 |
| 3D 静磁 | 端轴短磁体、径向/多极、偏心、倾斜、离轴、复杂屏蔽 | 计算量大；设置错误更难发现 |

### 常见误用

- **把直径充磁的圆柱当成轴对称。** 直径充磁的磁化矢量不绕轴旋转对称，轴对称模型无法表示。
- **把多极环压成 2D 轴对称。** 极距、相位和周向漏磁被抹掉，角度波形会完全错误。
- **用 2D 切片预测短磁体端面场。** 端部漏磁和轴向分量被忽略，气隙稍大就偏离。
- **在 2D 中模拟偏心。** 偏心破坏平移不变性，2D 平面模型无法正确表示。

FEMM 手册明确其 2D 平面/轴对称低频适用范围 [SIM-01](../sources/vendor.md#SIM-01)。如果几何或磁化不满足前提，换 3D 或做 3D 抽查，而不是硬调 2D 参数。

## 材料设置

### 软磁

- 使用**非线性 BH 曲线**，不要用单一恒磁导率处理饱和区。
- 曲线要覆盖实际工作场；超出范围时软件可能线性外推，导致虚假的高 $B$。
- 冲剪、叠压、热处理会改变性能；仿真用的是材料曲线还是成品曲线要说明。
- 叠片在各向异性/涡流上可能需要特殊处理；静磁分析通常不直接给出高频损耗。

### 永磁

常见线性模型：

$$
B=\mu_0\mu_{rec}H+B_r
$$

其中 $\mu_{rec}$ 是回复相对磁导率，$B_r$ 是剩磁。它适合在退磁曲线线性段工作、且不接近膝点的场景。若要评估高温/强反向场退磁，应使用完整的第二象限曲线或非线性永磁模型。

必须确认：

- $B_r$ 对应的温度；
- 磁化方向（单位矢量/局部坐标）；
- 是径向、轴向、直径还是多极分布；
- 是否考虑镀层、胶层和装配应力；
- 供应商曲线与仿真输入是否同一牌号/批次。

COMSOL 的永磁模型说明使用 $B=\mu_0\mu_{rec}H+B_r$ 并讨论空气盒/无限元等设置 [SIM-06](../sources/vendor.md#SIM-06)，但这只是实现示例，边界和网格仍需项目验证。

## 边界与空气域

- **开放场：** 使用足够大的空气域、无限元/无限盒或远场边界。
- **空气域尺寸：** 没有通用倍数。逐步扩大，观察敏感区场和角度误差变化；若变化小于预算，才可接受。
- **对称边界：** 仅在几何、材料、磁化和传感器位置都满足对称性时使用。直径充磁、偏心、倾斜通常破坏对称。
- **远场零场假设：** 无限盒假设无穷远场为零；如果外部源（电机、相邻磁体）存在，应把源纳入模型或另做叠加。

Altair Flux 文档指出无限盒尺寸没有通用规则，应扩大并加密做敏感性 [SIM-04](../sources/vendor.md#SIM-04)。这与“默认设置能算”是两回事。

## 网格与收敛

### 加密位置

- 磁体边缘、极尖、气隙；
- 传感器敏感体积；
- 磁导件拐角、螺钉、屏蔽开口；
- 磁化方向急剧变化处。

### 收敛判断

至少做三级网格（粗/中/细），比较**观测量**：

- 传感器体积平均 $B_x/B_y/B_z$；
- 场幅值与角度；
- 角度误差的 1×/2× 谐波；
- 全域能量或力矩（若相关）。

求解器的能量误差/自适应 Percent Error 只是停止条件，不等于局部场准确。Ansys Maxwell 的自适应设置可用 Percent Error 和 Max Passes 终止 [SIM-03](../sources/vendor.md#SIM-03)，但还要单独验证敏感体积的场。

### 边界敏感性

把空气域扩大 1.5×、2×，或把无限盒距离增加，观察观测量是否变化。若角度误差随边界尺寸明显漂移，说明边界仍在“参与”结果。

## 参数化与敏感性

至少扫描：

- 转子角度 0–360°，步长要能分辨目标谐波；
- 气隙最小/标称/最大；
- 径向偏心、轴向偏移、倾斜；
- 磁体 $B_r$、$H_{cJ}$、回复磁导、磁化角偏差；
- 磁体尺寸/圆度/充磁深度公差；
- 温度（$B_r$、软磁 BH、尺寸）；
- 屏蔽件/螺钉的材料与位置。

输出不仅要有云图，还要有：

| 参数 | 变化范围 | 角度误差最大值 | 1× | 2× | 备注 |
| --- | --- | --- | --- | --- | --- |
| 气隙 |  |  |  |  |  |
| 径向偏心 |  |  |  |  |  |
| 倾斜 |  |  |  |  |  |
| $B_r$ |  |  |  |  |  |
| 磁化角 |  |  |  |  |  |

敏感性排序比单点云图更有用：它告诉客户“先控制哪个公差”。

## 与实测关联

仿真是模型，不是证据。关联步骤：

1. 用三坐标/工装记录实际几何和气隙；
2. 用高斯计测传感器位置的场分量，记录探头方向和敏感体积；
3. 用转台扫描角度，记录参考角、温度和转速；
4. 用相同坐标、相同平均方式从仿真提取；
5. 比较 $B_x/B_y/B_z$、幅值、相位和角度误差，不只看云图“像不像”；
6. 分开校准集和验证集；
7. 报告残差和不确定度，不只报“趋势一致”。

Ansys 的电磁算例相关性文档提醒，高梯度、弱场和探头相对尺寸会放大会引入的误差 [SIM-07](../sources/vendor.md#SIM-07)。编码器气隙正是高梯度区，探头平均和位置误差必须纳入。

## 推荐报告结构

```text
1. 问题与观测量
2. 几何/坐标/单位（含简化及理由）
3. 材料与温度（曲线来源、牌号、批次）
4. 永磁模型与磁化方向
5. 边界、空气域及敏感性
6. 网格与收敛（至少三级）
7. 参数扫描与结果表
8. 与实测的相关性、残差、不确定度
9. 结论适用范围与未验证项
10. 文件/版本/作者/日期
```

## 常见误区

!!! warning "仿真最容易错的地方"
    1. 把直径充磁/多极磁体当轴对称。
    2. 用恒磁导率处理饱和软磁。
    3. BH 曲线范围不足，软件线性外推。
    4. 只增大网格数量，不检查观测量收敛。
    5. 只做单点探头，不做敏感体积平均。
    6. 空气域太小，边界影响结果。
    7. 用一组实测调参数，再宣称模型已验证。
    8. 只给云图，不给输入、版本、残差和适用边界。
