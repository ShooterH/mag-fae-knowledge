# 来源库

这里登记知识库实际引用的资料。正文中的来源 ID 必须能在本库找到对应条目；没有来源的工程判断要明确标为“工程推导”或“待实测”。

## 证据等级

| 等级 | 来源类型 | 可以支持什么 | 不能自动支持什么 |
| --- | --- | --- | --- |
| A | 计量机构、标准组织、政府/大学公开资料 | 量、单位、测试方法、标准定义 | 某型号在客户结构中的性能 |
| B | 原厂数据手册、应用笔记、官方软件文档 | 指定型号/版本的参数、条件、实现限制 | 泛化到其他型号或所有工况 |
| C | 正式出版教材、同行评审论文 | 概念、机理、经典模型 | 最新器件状态、项目保证值 |
| D | 内部推导、现场经验、未公开测试 | 形成假设、指导下一步验证 | 不能作为公开的普适结论 |

!!! info "引用格式"
    - 教材：`[BOOK-01，§x.x，书 p.xx / PDF p.xx]`
    - 外部资料：`[ENC-04]`，链接到[官方资料](vendor.md)中的完整登记。
    - URL 均记录访问日期；链接内容若更新，以版本号、发布日期和正文适用范围共同判断。

## 还不能说的事

- 教材为扫描件，首版只核对目录、章节起始页与文中列出的对应关系；**未完成全书 OCR**。
- 器件资料中的典型气隙、精度和校准收益均绑定测试条件，不能直接作为客户项目的保证值。
- 部分标准原文需要付费获取；本库只引用公开的书目信息或计量机构公开定义，不复制受限正文。
