# 来源库

这里登记知识库实际引用的资料。正文中的来源 ID 必须能在本库找到对应条目；没有来源的工程判断要明确标为“工程推导”或“待实测”。

## 证据等级

| 等级 | 来源类型 | 可以支持什么 | 不能自动支持什么 |
| --- | --- | --- | --- |
| A | 计量机构、标准组织、政府/大学公开资料 | 量、单位、测试方法、标准定义 | 某型号在客户结构中的性能 |
| B | 原厂数据手册、应用笔记、官方软件文档 | 指定型号/版本的参数、条件、实现限制 | 泛化到其他型号或所有工况 |
| C | 正式出版教材、同行评审论文 | 概念、机理、经典模型 | 最新器件状态、项目保证值 |
| D | 内部推导、现场经验、未公开测试 | 形成假设、指导下一步验证 | 不能作为公开的普适结论 |

!!! info "引用格式"
    - 教材：`[BOOK-01，§x.x，书 p.xx / PDF p.xx]`
    - 外部资料：`[ENC-04]`，链接到[官方资料](vendor.md)中的完整登记。
    - URL 均记录访问日期；链接内容若更新，以版本号、发布日期和正文适用范围共同判断。

## 本地归档与公开边界

教材与原厂资料的**查阅副本不存放在本仓库**，统一归档在维护者本地项目外目录；仓库只保留书目信息、来源 ID、URL 和适用边界。

| 内容 | 仓库内 | 项目外归档 |
| --- | --- | --- |
| 教材《磁学基础与磁性材料》第 2 版 | 书目、ISBN、页数、SHA-256、章节定位 | 完整扫描 PDF |
| 原厂数据手册、应用笔记、论文、官方网页 | 版本、URL、访问日期、支持与边界 | 下载副本及其校验值 |
| 站内文章与配图 | 原创归纳、原创示意图 | 不适用 |

归档目录结构（维护者本机）：

```text
参考资料/mag-fae-knowledge/
├── textbook/     # BOOK-01 扫描件
├── vendor/       # 按来源 ID 命名的手册、应用笔记、论文、官方网页
├── SOURCES.md    # 来源 ID 与归档文件对应表
├── archive-status.csv  # 下载状态、字节数、SHA-256
└── download-manifest.csv
```

**获取限制记录（2026-10-26）：** ENC-05（Melexis）、ENC-08（TDK-Micronas）官网返回 403，ENC-07 返回的是人机验证页，ENC-01 仅能取得摘要页；SIM-05（COMSOL）连接超时。这些条目在站内只作为“待补来源”列出，不作为已查阅事实的依据。取得正文后应更新归档状态，再在正文补充具体条件。

**为什么不进仓库：** 教材和原厂 PDF 受版权或分发条款限制，且二进制文件会让 Git 历史膨胀、难以审核。仓库只需能追溯到来源 ID 与版本；归档副本由维护者本地保存。

## 还不能说的事

- 教材为扫描件，首版只核对目录、章节起始页与文中列出的对应关系；**未完成全书 OCR**。
- 器件资料中的典型气隙、精度和校准收益均绑定测试条件，不能直接作为客户项目的保证值。
- 部分标准原文需要付费获取；本库只引用公开的书目信息或计量机构公开定义，不复制受限正文。
